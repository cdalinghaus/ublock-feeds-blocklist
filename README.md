# ublock-feeds-blocklist
This is my personal ublock origin blocklist that I use to remove "optimized-for-engagement"-feeds from browser.


Usage:
1. Open Ublock Origin Settings
2. Go to "Filter lists"
3. Click "Import..."
4. Add `https://raw.githubusercontent.com/cdalinghaus/ublock-feeds-blocklist/refs/heads/main/blocklist.txt` into the textarea
6. Click "Apply Changes"
